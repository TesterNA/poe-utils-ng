Notes
Why priorities and not amounts: reaching a target value costs exactly that much value however you split it, so there is no cheaper mix — the planner spends the value out of whatever you rank lowest, and only shuffles goods at the tail end to land on the number exactly.
Quotas (Favoured Resources) roll between +20% and +100% and multiply that resource's contribution to shipment value, so a quota'd resource is worth more per unit here. Quotas carry over between shipments and never expire.
Dust tops a shipment up 1:1 while it stays under the value of the real goods, then falls off — past that point total = goods × (1 + √(dust / goods)). Dust does not count towards quotas and does not affect how many Runegrafts or Tattoos you get.
Shipping ores and bars returns currency, whose rarity scales with the number of minerals sent rather than the shipment value. Crops return equipment. Bars are worth roughly 4x their ore, so shipping bars costs fewer units for the same value.
